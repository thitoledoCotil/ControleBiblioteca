Controle da Biblioteca Rodrigo Garro
Feito por: Thiago Toledo Dapolito - 2°DSD
O sistema conta com algumas funções como:
1- Organização dos livros por gênero
2- Ler código de barras para empréstimo
3- Enviar alerta no telefone do cliente quando o prazo de empréstimo estiver finalizando
4- Aba de feedback dos leitores que pegaram o livro emprestado
5- Renovar empréstimo

O Objetivo do sistema é automatizar a organização lógica dos livros e clientes da Biblioteca Rodrigo Garro, além de facilitar os empréstimos para o cliente.
O público-alvo são pessoas que possuem o hábito e o hobby de adquirir conhecimento ou entretenimento através de livros que são disponibilizados pela Biblioteca Rodrigo Garro.
Suas funcionalidades estão citadas acima.
